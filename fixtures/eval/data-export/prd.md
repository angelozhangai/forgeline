# User data export

## Background
Users want to export their data from the platform for backup and migration. Support has fielded several "how do I get my data" requests recently.

## Requirement
- Add an "Export my data" button under "Settings - Privacy".
- Clicking it makes the system generate a file the user can download.
- Notify the user when the export is ready.

## Acceptance
- The user can trigger an export from the settings page.
- A file can be downloaded.
